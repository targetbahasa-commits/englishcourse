# Ambient Sound Files

Place loopable ambient background MP3 files in this directory.

## Required Files
| Filename          | Description                        |
|-------------------|------------------------------------|
| `cafe.mp3`        | Coffee shop / cafe ambience        |
| `airport.mp3`     | Airport terminal background noise  |
| `library.mp3`     | Quiet library room tone            |
| `office.mp3`      | Open-plan office ambience          |
| `classroom.mp3`   | Empty/light classroom hum          |
| `street.mp3`      | Outdoor street background          |

## Free CC0 Sources
Download royalty-free ambient loops from:
- https://freesound.org (filter: CC0 license)
- https://pixabay.com/sound-effects/ (free commercial use)
- https://soundbible.com

## Recommended Duration
Each file should be at least **30 seconds** long.
The service will loop and trim automatically to match speech duration.
