Auto-Save Test Page

Testing Instructions:

  1. Open Console (F12)
  2. Type 1 letter in Question 1
  3. Check console for logs
  4. Check for green badge at bottom-left
  5. Refresh page (F5)
  6. Verify data is restored

Console Commands:

// Check if AutoSave loaded
console.log('AutoSave:', typeof AutoSave);

// Check storage key
console.log('Key:', AutoSave.storageKey);

// View saved data
console.log('Data:', localStorage.getItem(AutoSave.storageKey));

// Manual save
AutoSave.saveAnswers();

// Manual restore
AutoSave.restoreAnswers();
